About

Pengo is a small internet built from scratch. It has its own protocol, its own name server and its own browser. Nothing here runs on HTTP.

  • the Pengo protocol — instead of HTTP
  • Pengo DNS — instead of DNS, one flat file of names
  • pengo-browser — instead of Chrome

A site is just a folder. Start the server inside it and it is online. No config, no account, no registrar.

None of this needed to exist. That is roughly the point.
